CLI quickstart


Three commands, in order. Paste and run.






01Check a folder
terminal - check
$docscribe lib
$? 1 here means missing docs, fix with step 02


02Safe fix in place
terminal - safe fix
$docscribe -a lib
$? 0 means clean, commit the diff


03Sync inferred types, file-scope
terminal - type sync
$docscribe update_types lib
$? 0 means synced, 2 means read the errors

Designed, not grown


CLI parses with the parser gem (Prism on Ruby 3.4+), collects methods, then infers types through RBS, Sorbet, and plugin signatures before rewriting the file, safe or aggressive. A daemon keeps parsed files behind a Unix-socket JSON-RPC with a 1000-entry LRU cache, so editor checks return instantly.













CLI Entry point. Flags, file list, exit codes 0/1/2.
